# Thực hành thẻ liên kết trong HTML (<a>)

Bài thực hành luyện tập sử dụng thẻ liên kết `<a>` để điều hướng trang web.

## Nội dung bài tập
- File chính: `index.html`
- File liên kết nội bộ: `about.html`
- Tiêu đề `<h1>`: "Liên kết yêu thích của tôi"
- Danh sách `<ul>`: Chứa 3 liên kết đến các website khác nhau
- Liên kết mở trong tab mới: `target="_blank"`
- Liên kết nội bộ đến `about.html`
- Liên kết gửi email: `mailto:dtc245180016@ictu.edu.vn`
